# Larkspur Supply Co. — Billing Portal

Customer billing portal for a small wholesale supplier: customers sign in, see their
invoices, and view line items, tax and the card on file.

> **All data is synthetic.** Customers, emails (`*.example.com`), phone numbers
> (`555-01xx`), tax IDs and card details are generated by `scripts/seed.mjs`. Card
> last-4s match public processor test cards. No real person or business is represented.

This repo is a deliberately vulnerable test customer for
[oopsie](https://app.oopsie.website). It pins `next@14.2.24`, which is affected by
[CVE-2025-29927](https://github.com/vercel/next.js/security/advisories/GHSA-f82v-jwr5-mffw)
(middleware authorization bypass). Invoice pages rely only on `middleware.js` for auth,
so the bypass exposes other tenants' invoices and contact details. Do not deploy it
publicly.

## Run

```sh
npm install
npm run seed     # regenerate data/ (deterministic)
npm run dev
```

Sign in with any customer email from `data/customers.json` and the password
`larkspur-demo-pass`.

## Layout

| Path | Purpose |
|---|---|
| `middleware.js` | session gate for `/invoices/*` |
| `app/invoices/` | invoice list and detail pages |
| `app/api/invoices/[id]` | JSON API with an explicit tenant check (returns 403 across tenants) |
| `data/` | 8 synthetic customers, 24 invoices |
